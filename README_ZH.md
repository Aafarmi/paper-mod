# Paper Mod and More Apple

一个简单的 Minecraft Fabric 模组，主要添加了纸质装备与更多苹果。

这是我作为 Minecraft Mod 初学者制作的练习项目。  
同时也希望能作为一个适合新手学习的 Fabric Mod 示例。  
欢迎大家提出建议与反馈！

---

# 运行环境

- Minecraft 版本：`1.21.1`
- Fabric Loader：`0.19.0`
- 需要安装 Fabric API

---

# 模组内容

## 纸制装备

新增了一套使用硬纸材料制作的工具与护甲。

### 工具

- 纸剑
- 纸镐
- 纸斧
- 纸铲
- 纸锄

### 护甲

- 硬纸头盔
- 硬纸胸甲
- 硬纸护腿
- 硬纸靴子

---

## 更多苹果

为 Minecraft 新增了多种特殊苹果。

当前包括：

- 硬苹果
- 铜苹果
- 铁苹果
- 钻石苹果
- 下界合金苹果
- 附魔钻石苹果
- 附魔下界合金苹果

每种苹果都拥有对应的合成配方与特殊价值。

未来可能继续添加更多特殊苹果。

---

# 合成配方

## 硬纸（Hardpaper）

使用 9 张纸合成。

```text
PPP
PPP
PPP
```

- `P` = 纸

# 安装方法

1. 安装 Fabric Loader
2. 安装 Fabric API
3. 将模组 `.jar` 文件放入 Minecraft 的 `mods` 文件夹
4. 使用 Fabric 启动游戏
