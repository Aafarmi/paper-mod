# Paper Mod and More Apple

A simple Minecraft Fabric mod that adds paper equipment and more apples.

This mod is my beginner attempt at Minecraft mod development.  
It is also intended as a learning project for new mod developers.  
Suggestions and feedback are welcome!

---

# Environment

- Minecraft Version: `1.21.1`
- Fabric Loader: `0.19.0`
- Fabric API Required

---

# Features

## New Paper Equipment

Added a full set of paper-style tools and armor crafted from hardened paper materials.

Including:

### Tools

- Paper Sword
- Paper Pickaxe
- Paper Axe
- Paper Shovel
- Paper Hoe

### Armor

- Hardpaper Helmet
- Hardpaper Chestplate
- Hardpaper Leggings
- Hardpaper Boots

---

## More Apples

Added several new apples to Minecraft.

Current additions include:

- Hard Apple
- Copper Apple
- Iron Apple
- Diamond Apple
- Netherite Apple
- Enchanted Diamond Apple
- Enchanted Netherite Apple

Each apple has its own crafting recipe and special value.

More apples may be added in future updates.

# Installation

1. Install Fabric Loader
2. Install Fabric API
3. Put the mod `.jar` file into your Minecraft `mods` folder
4. Launch the game with Fabric
